# Aguttes (Paris / Lyon)

Aguttes, "Instruments & Archets du quatuor" department: **June 2022 – May 2026**, 9 sales, the sold lots of the house's
site (aguttes.com; the site shows no unsold lot). Collected 18 Oct 2026.

One file per sale: `<date>_aguttes_<sale number>.csv`.

| Column | Meaning |
|---|---|
| sale_number, sale_date | as published |
| lot, stock_number | the lot number; the house's stock number |
| artist, title_fr, subtitle_fr, description_fr, description_en | as published (French, and the house's English where given) |
| status | sold |
| estimate_low, estimate_high | the house's estimate, EUR |
| hammer | hammer price (adjudication), EUR |
| buyer_premium_excl_vat, seller_commission_excl_vat | the fees in the lot's data on the house's site, before VAT, EUR (empty where not given) |
| source | Primary: published by the house itself |

Buyer's premium: 25 % + VAT up to EUR 150 000, 23 % + VAT above (June 2022); 20 % + VAT (June 2023 – Nov 2024); 21 % + VAT
(Nov 2025 – May 2026).
