# Amati (London)

Amati's own online auctions, 2018-2026, from the house's results pages: one file per sale day.

## About the house
Amati is a London online auction house for violins, violas, cellos and bows, started in 2013 by James Buchanan and run as a family firm; it holds at least ten sales a year (specialist, affordable and single-owner collection sales), most instruments coming from private sellers.
Source: [Amati (own site)](https://amati.com/about/), checked 2026-11-03.
